# Exclusive acquisition: Smart Expense Manager Android app

## Listing headline

Android expense-management app with automatic bank-SMS transaction parsing,
local analytics, budgeting, categorization, and AI-insight capabilities

## Executive summary

Smart Expense Manager is a Kotlin Android application built for users who want
to turn bank and payment transaction messages into an organized expense history
without repetitive manual entry. The product includes a working Android client,
an extensible transaction-parsing pipeline, local financial data storage,
dashboards, category and merchant management, budgeting, exports, and optional
online insights.

This is an **exclusive full-asset sale**, not a template or non-exclusive source
license. The intended buyer is a fintech, accounting, employee-expense,
personal-finance, or mobile-app business that can operate and grow the product.

## Product capabilities

- Incoming and historical financial-SMS ingestion
- Rule-driven transaction and merchant parsing
- Debit, credit, card, and UPI payment-method handling
- Searchable transaction history with editing and deletion
- Merchant cleanup and automatic/custom categorization
- Dashboard totals, trends, category splits, and top merchants
- Overall and category budgets with alerts
- Recurring-transaction detection
- CSV and other data-export workflows
- Offline insights plus an optional remote AI-insights integration
- Guided first-run product tour
- Google Play release and store-listing automation

## Technology

- Kotlin, XML layouts, and ViewBinding
- MVVM-style presentation with ViewModels, Flow, and coroutines
- Room local database
- Hilt dependency injection
- Retrofit and OkHttp networking
- Firebase Authentication and Google Sign-In integration
- Android Navigation Component and Material Design
- Fastlane-based Google Play release workflow
- Target SDK 36, minimum SDK 24
